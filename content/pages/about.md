你好，我是 **Lushio**。

白天写代码，晚上读书，偶尔在两者之间写一点东西。这个博客是我在互联网上的一个小小房间，用来存放那些不想被信息流冲走的部分。

## 这里有什么

- **技术笔记**：Web 开发、工具、以及那些踩过的坑。
- **阅读与生活**：书、电影、散步，和一些没有结论的念头。
- **正在生长的想法**：关于创造、注意力和如何过日子。

我不追求更新频率，也不打算把它做成一个内容产品。这里更像一座花园：有的地方开得热闹，有的地方空着，等下一颗种子。

## 关于写作

我相信缓慢的写作仍然有意义。

不是为了说服谁，也不是为了证明什么，只是把看见的东西认真记下来。如果这些文字恰好对你有用，或者让你想起了自己的某件事，那就很好。

> 写作不是为了被看见，而是为了把看见的东西留下来。

## 找到我

这个网站使用纯 Node.js 静态生成，托管在 GitHub Pages 上。你可以在 [GitHub](https://github.com/lushio69) 找到我，也可以订阅 [RSS](/feed.xml)，在新文章发布时收到提醒。

如果你想说点什么，欢迎在 GitHub 上开一个 issue。也可以在 `site.config.json` 里加上你的邮箱或社交账号，把这一节换成自己的联系方式。

谢谢你来过。
